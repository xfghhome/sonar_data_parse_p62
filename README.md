# P62 文件解析器

全向声呐数据文件（.P62）的解析与可视化工具。

## 文件格式说明

根据文件结构分析，.P62 文件包含：

- **文件结构**：固定长度记录（每条 695 字节）
- **记录数**：1506 条
- **每条记录包含**：
  - **头部（21 字节）**：
    - 0x00-0x03: Magic 标识 `FE 14 10 01`
    - 0x04-0x07: Unix 时间戳（uint32 小端）
    - 0x08-0x09: 方位索引（uint16 小端，范围 0-1567）
    - 0x0A-0x0B: 参数1（1313）
    - 0x0C-0x0D: 参数2（1348，距离采样点数）
    - 0x0E-0x0F: 量程设置（50，表示 5.0 米）
    - 0x10-0x11: 编码器分辨率（1568，对应 360°）
    - 0x12-0x13: 参数3
    - 0x14: 状态字节
  - **回波数据（674 字节）**：
    - 从 0x15 开始
    - 包含 1348 个 4-bit 强度样本（每个字节包含 2 个样本）
    - 强度范围：0-15

## 使用方法

### 1. 基本解析（不生成图像）

```bash
python parse_p62_simple.py 222.P62
```

输出文件统计信息和前几条记录的详情。

### 2. 完整解析与可视化

```bash
# 生成所有可视化
python parse_p62.py 222.P62 --all

# 或选择特定视图
python parse_p62.py 222.P62 --polar      # 极坐标视图
python parse_p62.py 222.P62 --cartesian  # 笛卡尔坐标视图
python parse_p62.py 222.P62 --scan       # 扫描模式图

# 导出数据为 NumPy 格式（便于后续分析）
python parse_p62.py 222.P62 --export sonar_data.npz
```

## 输出文件

### 可视化图像
- `polar_view.png` - 极坐标视图（俯视，0°在顶部）
- `cartesian_view.png` - 笛卡尔坐标视图（平面投影）
- `scan_pattern.png` - 扫描模式（方位索引随时间变化）

### 数据导出
使用 `--export` 选项可以导出解析后的数据为 NumPy 压缩格式（.npz），包含：
- `timestamps` - 时间戳数组
- `azimuth_indices` - 方位索引数组
- `angles_deg` - 角度数组（度）
- `angles_rad` - 角度数组（弧度）
- `intensity` - 强度矩阵（方位数 × 距离采样点数）
- `range_max` - 最大量程（米）
- `num_samples` - 距离采样点数
- `encoder_res` - 编码器分辨率

加载示例：
```python
import numpy as np
data = np.load('sonar_data.npz')
intensity = data['intensity']
angles = data['angles_rad']
```

## 数据说明

- **时间戳**：Unix 时间戳（秒级）
- **方位角**：`角度 = (方位索引 / 1568) × 360°`
- **距离分辨率**：`dr = 5.0 m / 1348 ≈ 3.71 mm`
- **回波强度**：4-bit 值（0-15），表示每个距离单元的回波强度

## 注意事项

1. **角度方向**：默认 0° 在顶部（北），顺时针方向。如需调整，修改 `parse_p62.py` 中的 `ax.set_theta_zero_location()` 和 `ax.set_theta_direction()`。

2. **时间戳**：文件中的时间戳为 Unix 时间戳。示例文件显示为 2025-04-02，这可能是设备时钟设置问题或时间戳格式需要进一步验证。

3. **4-bit 解包顺序**：当前实现假设低 4 位在前，高 4 位在后。如果实际数据顺序相反，需要调整解包逻辑。

4. **距离映射**：假设量程设置字段的单位是 0.1 米（50 → 5.0 米）。如果实际单位不同，需要调整 `range_max` 的计算。
